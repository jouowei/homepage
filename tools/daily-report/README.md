# 日報表司機欄自動填寫

每個月的固定流程：把車輛日報表和各群組的 LINE 出勤名單丟進 `inputs/`，跑一行指令，
`outputs/` 就會出現填好司機的報表和一份檢核報告。

## 一次性準備

```bash
pip install openpyxl
```

## 每月流程

**1. 清空 `inputs/`，放進這個月的檔案**

| 放什麼 | 幾個 | 命名 |
|---|---|---|
| 車輛日報表 | 剛好 1 個 `.xlsx` | 隨意，檔名會用在輸出上 |
| LINE 出勤群組匯出 | 任意多個 `.txt` | **檔名就是群組名稱**，會出現在檢核報告裡，建議用 `早班群.txt`、`夜配群.txt`、`大車群.txt` |
| `設定.json` | 0 或 1 個 | 選用，見下方 |

LINE 匯出方式：聊天室 → 選單 → 設定 → 傳送聊天紀錄 → 存成 txt。

**2. 執行**

```bash
cd tools/daily-report
python3 fill_driver.py
```

**3. 到 `outputs/` 取檔**

- `<原檔名>_已填司機.xlsx` — 完整活頁簿，月報表／日報表／細項都在，只有日報表 A 欄被填上
- `日報表_YYYYMM.xlsx` — 單獨匯出的日報表分頁，已凍結標題列、調好欄寬
- `對應檢核報告.txt` — **每次都要看**，見下方

## 程式怎麼判讀名單

不用改程式，格式會自動偵測：

- **標題列**：訊息裡出現 `7/1出勤`，或整列就是 `7/1`
- **名單列**：`153吳宗賢`（車號在前）或 `葉宏傑9310`（姓名在前），同一個群組用哪種寫法會自動判斷
- **會略過**：空白列、`休：…`、`新人○○跟063`、`廠休`、`台東` 這類小標和說明
- **年份**：名單只寫月/日，年份取自日報表本身的日期欄，跨年也不會錯

車號用數字段對應：`063` → `063-Q8`、`7901` → `KLM-7901`、`9310` → `KPB-9310`。

**更正訊息會整份覆蓋。** 同一天同一群組貼過好幾次出勤表時，只採用最後一次公布的那份。
這點很重要 —— 例如某天原本是 `335黃信銓`、更正後變成 `067黃信銓`，若只逐筆疊加，
335 那天會留下錯誤的名字。

## 檢核報告要看什麼

| 段落 | 代表什麼 | 怎麼處理 |
|---|---|---|
| `未解析 7/5：'…'` | 名單區塊裡有讀不懂的列 | 多半是休假名單或閒聊，確認不是漏掉的司機就好 |
| `出勤表有更正` | 該日採用了最後一次公布的版本 | 通常正確，可略 |
| `衝突` | 兩個群組對同一台車同一天寫了不同的人 | 一定要人工確認，程式保留先讀到的那個 |
| `同一天掛到兩台以上車輛的司機` | 某群組可能漏了更正 | 對照日報表的行駛時數判斷他實際開哪台，再用 `overrides` 修正 |
| `有行駛紀錄但出勤名單沒列到的車輛` | 這些車沒有對應的群組名單 | 天數多的（例如整月 31 天）代表缺一整個群組的紀錄 |
| `出勤名單有、但日報表查無該車該日的紀錄` | 名單有寫，但日報表缺那一列 | 通常是報表來源缺資料 |

## `設定.json`（選用）

處理程式讀不出來的個案。複製 `設定.範例.json` 到 `inputs/設定.json` 再改：

- **`aliases`** — 同一個人在不同群組被打成不同的字（例如 `鐘`／`鍾`），在這裡統一
- **`overrides`** — 用文字描述而非標準名單格式的更正。`動作` 填 `新增` 或 `移除`，
  `日期` 用 `yyyymmdd`，`車號` 填名單上的數字代碼

例如群組裡有人補了一句「5日326夜配有出勤忘記更正」，程式讀不出來，就加一筆 `新增`。

## 欄位位置不同時

預設 A=司機、B=車號、C=日期、D=上班時間。若日報表格式改了：

```bash
python3 fill_driver.py --driver-col 1 --plate-col 2 --date-col 3 --work-col 4 --sheet 日報表
```

也可以指定別的資料夾：

```bash
python3 fill_driver.py 某個資料夾 --output-dir 另一個資料夾
```

## 注意

`inputs/` 和 `outputs/` 的內容含有員工姓名，已經寫在 `.gitignore` 裡不進版控。
如果要保留每個月的 `設定.json`，請放在版控之外的地方。
